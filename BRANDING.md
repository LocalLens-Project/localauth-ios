# Branding Scope

The source code in this repository is licensed under Apache-2.0. That does not
mean every non-code asset in the repository is freely reusable as project
branding.

The following items are excluded from the Apache-2.0 grant unless the copyright
owner gives separate written permission:

- Published product and application names used as brand identifiers
- Organization names, logos, icons, and other visual identity assets
- App Store screenshots, listing copy, promotional images, and similar marketing
  materials

If you publish a fork, a derived app, or a redistributed build, replace these
brand-facing assets with your own before shipping it under a new public identity.
